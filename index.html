How to Use This App

  • Upload Photo: Select an image to generate patterns based on its colors.
  • Select Pattern: Click a pattern thumb on the left. Smart Mix uses brightness to pick patterns; Random Flow uses noise.
  • Set Empty Areas: Click any part of the rendered canvas to set that color as the "Void Color," which removes patterns from areas matching that tone.
  • Adjust Detail: Use the Density slider to change cell size, or use your mouse wheel over the canvas to scroll density.
  • Wood Palette: Use Color Steps to limit the number of unique wood colors in your design.
  • Bill of Materials: Check the right sidebar for the exact count of pieces needed for each pattern and color combination.
